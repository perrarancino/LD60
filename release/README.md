# Редактор уровней LD60

`LD60Editor.exe` — редактор уровней одним файлом (Windows 10/11, любой браузер; Node.js не нужен).

1. Скачайте репозиторий (Code → Download ZIP или `git clone`).
2. Запустите `release/LD60Editor.exe` двойным щелчком — редактор откроется в браузере по умолчанию.
   Exe ищет проект рядом (папка выше `release`); если лежит в другом месте — спросит папку проекта (где есть `data` и `assets`) и запомнит её.
3. Правки сохраняются в `data/levels/*.json`; кнопка «▶» запускает игру на текущем уровне.

Окно браузера закрыли — exe сам завершится. Подробности — в [`data/README.md`](../data/README.md).
