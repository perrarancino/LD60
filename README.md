# LD60

## Запуск

- Разработка: `npm install` → `npm run dev`.
- Один файл для запуска: `npm run exe` собирает `release/LD60.exe` (двойной клик — игра откроется в браузере
  по умолчанию; сервер встроен в exe и сам закрывается, когда закрыта вкладка). Нужны Node.js и Windows (.NET Framework 4).
  Подробности — `tools/launcher/`.
