# LD60

## Запуск

- Разработка: `npm install` → `npm run dev`.
- Один файл для запуска: `npm run exe` собирает `release/LD60.exe` (двойной клик — игра откроется в браузере по умолчанию;
  сервер встроен в exe и сам закрывается, когда закрыта вкладка). Нужны Node.js и Windows (.NET Framework 4).
  Пока exe лежит в `release/` внутри проекта, **перезагрузка страницы (F5) сама пересобирает игру**, если исходники изменились
  (около 3 с; ошибки сборки показываются на странице). Вне проекта exe запускает вшитую копию игры. Подробности — `tools/launcher/`.
